# 🏺 Sphinx Semantic AI

Sphinx Semantic AI is a state-of-the-art, production-grade semantic search engine powered by a custom **Siamese Transformer** architecture. Designed with a blend of traditional Egyptian majesty and futuristic artificial intelligence, it provides deep contextual understanding for textual similarity tasks.

## ✨ Features

- **Custom Siamese Transformer**: Built from scratch with shared encoders, positional embeddings, and multi-head attention.
- **"Never Forgets" Training**: A robust replay-memory pipeline that persists training data and prevents catastrophic forgetting.
- **Premium Animated UI**: A state-of-the-art frontend featuring 3D tilt effects, mouse parallax, and dynamic gradient backgrounds.
- **Real-time Analytics**: Live dashboard for monitoring model statistics, training logs, and loss metrics.
- **Production Ready**: High-concurrency API powered by FastAPI and Uvicorn.

## 🏗️ Architecture

- **Encoder**: 6 Layers, 4 Attention Heads, 256 Embedding Dimension.
- **Tokenizer**: BERT (bert-base-uncased).
- **Loss Function**: Contrastive Loss with Margin.
- **Inference**: Optimized TensorFlow/Keras execution.

## 🚀 Quick Start

1. **Install Dependencies**:
   ```bash
   pip install -r requirements.txt
   ```

2. **Run the Server**:
   ```bash
   python3 app.py
   ```

3. **Access the Interface**:
   Open [http://localhost:8001](http://localhost:8001) in your browser.

## 🛠️ Tech Stack

- **Backend**: FastAPI, TensorFlow, Keras, Transformers.
- **Frontend**: Vanilla HTML5, CSS3 (Glassmorphism), Modern JavaScript.
- **Animations**: Canvas Particle System, 3D Perspective Tilt, CSS Keyframe Gradients.
